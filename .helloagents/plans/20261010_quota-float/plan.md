# Codex 额度浮窗 — 实施规划

## 目标与范围
交付能运行的 Windows 原生浮窗和演示渲染图。确认的第三线含义为 7 天周期已走过时间。

## 架构与实现策略
.NET 10 WPF + 无依赖 Core 库。主水柱与独立详情窗协同悬停，使用短延迟连接两窗；详情跟随停靠方向朝屏幕内展开。当前屏幕工作区约束位置，多显示器 DPI 换算；设置保存于 LocalAppData。数据由演示源或 CPA 管理源提供，刷新互斥、超时和错误显式显示。

## 领域语言
剩余百分比：100% 表示未使用。7d 时间：0% 表示周期刚开始，100% 表示已到周重置时间。水位：有效账号 min(5h剩余,周剩余) 的等权平均，不是可相加的 token 总量。过期窗口视为待刷新，不自动赠予额度。

## 完成定义
qaMode=standard。验证水位、周期、三色线、10 行分页、停靠/置顶、刷新状态、CPA 安全边界。真实 CPA 未联调须交付时声明；演示版功能不能依赖真实凭据。

## 文件结构
src/QuotaFloat.Core：模型/计算/数据源/CPA解析。src/QuotaFloat：主题/水柱/详情/设置/屏幕定位/应用生命周期。tests/QuotaFloat.Tests：离线确定性测试。artifacts：UI 自渲染截图。dist：发布版。

## UI / 设计约束
暖白半透明圆角详情面板与冷青水柱，细密刻度。蓝=5h、绿=周、橙=7d已走过时间；每项同时附文字。主浮窗48×240，水柱32×224。单账号小卡宽304、高度小于230，上下移动选择账号，滚轮切换并滚动最多10组横线的视口；刷新保持选择与位置。点击才打开全部列表，每页最多10条，按工作区高度滚动。字体 Segoe UI Variable Text / Bahnschrift。Escape收起、右键菜单、系统减弱动效。

## 风险与验证
CPA 分支接口差异：可配置管理路径，基于上游接口离线模拟验证，真实连接不声称完成。多屏/系统 DPI：屏幕工作区与物理/逻辑坐标转换。API 错误不显示100%；部分失效账号明确排除汇总并提示。截图由 WPF RenderTargetBitmap 原生生成，不冒充真实屏幕操作验证。
