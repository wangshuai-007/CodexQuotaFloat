## 数据与视觉
左蓝5h、右绿7天，独立按原有效账号均值映射42–278同一高度尺度，保留透明渐变与贝塞尔波浪。水面增加白色亮边及深色细描边，中央仅0.8px白缝，不新增槽底。
顶部两行直接标明窗口和百分比，满额略缩字号防裁切。深蓝#206A9D、深绿#116C55在#FDFDFC上约5.72:1、6.25:1；不只靠颜色区分。账号三色横线、底部Token/s和悬停功能不变，不恢复账号数量。
未知一侧显示破折号且无填充；零是真实空水位；旧数据降低透明度并保留旧标记。沿用系统减弱动效，只有真实额度变化时过渡，不加循环波浪或假流量。

## 视觉层级评审
### Entry Point · minor issue → 修正
观察：旧双模式百分比挤在16px列内，字号7，水面边缘较淡。
问题：窗口、数字和真实水位难以快速对应。
修正：完整两行直接标签、水面细描边，避免扩大浮窗或新增大数字。
### Eye Flow · minor issue → 修正
观察：账号短横线跨两侧，水面与中线不够清晰。
问题：容易误把单账号横线看成总体水面。
修正：总体使用连贯曲线和亮边，账号保持短三色直线；中缝明确左右高度独立。
### Weight · pass
观察：前一实心槽方案将液体做成短矩形。
问题：装饰容器压过水位高度，违背用户确认的表达。
修正：保留原全高液体，只调整轻薄色阶和表面边界，不增加框、徽章或图标。
### Emphasis · pass
观察：水位为主，账号与流量通过悬停查看。
问题：不应让新装饰或流量占据主视觉。
修正：不改流量区大小或交互；本次只优化水位编码。

## 验证范围
1倍尺寸与2倍预览；三种模式、相近水位、0/100、未知和旧数据；检查波浪与渐变保留、全高尺度、标签不裁切、颜色对比度及副屏交互。离线渲染不能替代物理鼠标人工验收。
